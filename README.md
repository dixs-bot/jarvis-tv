# JARVIS TV — YOUR WORLD. YOUR ENTERTAINMENT.

Next.js (App Router) + TypeScript + Framer Motion + HLS.js.

- `npm install && npm run dev` → http://localhost:5173
- `npm run typecheck`, `npm run lint`, `npm run build`
- Playlist: `NEXT_PUBLIC_PLAYLIST_URL` (default iptv-org Indonesia)
- Ads: paste Adsterra snippets into `config/ads.ts` (empty = placeholder)
- Admin-ready config: `config/admin.ts` + `services/` (swap `StaticAdminService` for Supabase later)
